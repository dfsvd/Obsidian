# team Deck 密码重置

## 进入 GRUB 修补模式

1. **重启设备**：在按住 steamdeck 的三个点+电源按键，启动时选择 `current steam os`，并移动到带有 `boot menu` 的选项。
![](images/Steam%20Deck%20密码重置/file-20260318194048018.jpg)
![](images/Steam%20Deck%20密码重置/file-20260318194048022.jpg)
2. **进入编辑界面**：在系统选择界面，反白选中 `SteamOS` 项目，按下键盘 **`E`** 键进入 GRUB 编辑模式。
![](images/Steam%20Deck%20密码重置/file-20260318194048025.jpg)
3. **定位关键行**：在代码编辑器中，寻找以 `steam_env_boot` 开头的那一行项目。
4. **添加调试参数**：
    - 将光标移动到该行代码的**最末端**。
    - 按下 **空格**。
    - **核心校正**：输入 `systemd.debug_shell`
![](images/Steam%20Deck%20密码重置/file-20260318194048027.jpg)
5. **执行启动**：按下 **`Ctrl + X`**，系统将带参数重新引导进入游戏模式。

---
## 切换终端重置密码
1. **进入命令列模式**：回到游戏界面后，按下组合键 **`Ctrl + Alt + F9`**。此时屏幕会切换至黑底白字的终端界面。
2. **输入重置指令**：
    ```    Bash
    passwd deck
    ```
3. **设置新密码**：
    - 按下 `Enter` 后，系统提示 `New password:`。
    - 输入您想设置的新密码（注意：**输入时屏幕不会显示任何字符**）。
    - 按下 `Enter`，系统提示 `Retype new password:`，再次输入相同密码并回车。
4. **确认成功**：看到提示 `password updated successfully` 即代表成功。

---
## 返回系统与验证

1. **切回界面**：按下 **`Ctrl + Alt + F1`** 回到 Steam 游戏模式界面。
2. **验证权限**：
    - 切换到**桌面模式 (Desktop Mode)**。
    - 尝试打开终端 (Konsole) 或进行软件更新。
    - 当系统弹出管理员权限请求时，输入您刚才设定的新密码即可。

> [!tip]
> - steamdeck 默认密码设置为 root（强密码只会卡自己）
> - 操作前准备好扩展器和鼠标键盘
