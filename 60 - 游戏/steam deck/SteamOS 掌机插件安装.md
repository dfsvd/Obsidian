# SteamOS 掌机插件安装
## 前期基础设置
### 切换语言为中文
1. 点击左下角菜单 → 电源 → 切换到**桌面模式**
2. 打开 `System Setting` → 拉到最底部找到 `Language` → 修改为中文
3. 重启设备后再次进入桌面模式
### 设置管理员密码
1. 点击左上角 Steam 图标 → 选择**修改密码** → 设置管理员密码
2. 打开终端，执行命令（输入密码时无显示，正常输入即可）
### 安装 SteamOS 万能工具箱
1. 桌面模式下打开系统设置 → 系统 → 启用**开发者模式**
2. 开发者模式中打开**CEF 远程调试**
3. 终端执行工具箱安装命令：
    ```bash
    curl -s -L https://gitee.com/soforeve/plugin_patch/raw/master/pp.sh | sh -
    ```
![](images/SteamOS%20掌机插件安装/file-20260318194049107.jpg)
4. 输入管理员密码，安装完成后输入`2`回车初始化国内软件源
5. 初始化完成按任意键返回菜单
6. 卸载工具箱命令：
```shell
curl -s -L https://gitee.com/soforeve/plugin_patch/raw/master/uninstall/uninstall.sh | sh -`）
```
### 4. 安装插件商店

1. 终端输入`8`回车 → 再输入`1`回车安装插件商店
2. 若插件商店图标（小插头）未显示，**重启设备**即可
3. 系统更新导致插件商店丢失时，执行最新安装命令：
    ```bash
    curl -L https://github.com/SteamDeckHomebrew/decky-installer/releases/latest/download/install_release.sh | sh
    ```
## 必备插件安装

### 开机动画插件：Animation Changer

- **功能**：免费使用官方商店需点数兑换的开机动画
- **操作**：
    1. 插件商店安装后打开 → 点击`Manage Animations`
    2. 搜索并下载喜欢的动画 → `Boot`中选择下载的动画
    3. 菜单设置→自定义 → 选中下载的动画生效
### 主题美化插件：CSS Loader
- **功能**：自定义界面主题、键盘主题，支持色彩细节调节
- **操作**：
    1. 安装后打开 → 下载主题（界面 / 键盘）→ 点击安装
    2. 齿轮图标启用主题，可调整风格；筛选切换为「键盘」可安装键盘主题
    3. 右上角齿轮可删除已下载主题
### 封面背景插件：SteamGridDB
- **功能**：自定义游戏 / 软件封面（学习版游戏也适用）
- **操作**：安装后菜单新增「更改封面」选项 → 按需替换封面
### 音效 / 背景音乐插件：Audio Loader
- **功能**：切换按键音效、自定义背景音乐
- **操作**：
    1. 安装后打开 → 点击`Manage Pack`
    2. `Audio`标签安装按键音效，`Music`标签安装背景音乐
    3. 上方选项控制按键音效，下方控制背景音乐；`Uninstall`删除音效

### 色彩优化插件：vibrantDeck
- **功能**：提升 SteamOS 偏暗的屏幕色彩
- **操作**：安装后仅调整**饱和度**（推荐 115-130），其余保持默认
### 游戏暂停插件：Pause Games
- **功能**：快速暂停游戏
- **操作**：安装后打开插件内 3 个选项 → 进入游戏后显示暂停按钮
### 兼容性评级插件：ProtonDB Badges
- **功能**：游戏库显示 ProtonDB 兼容性评级 + 玩家评论
- **操作**：插件商店搜索安装即可（无额外设置）
### 蓝牙优化插件：Bluetooth
- **功能**：快速连接已配对蓝牙设备，支持开机自动连接
- **操作**：插件商店搜索（需往下翻找）→ 安装后自动生效
### 修改器插件：CheatDeck

- **注意**：默认商店版本过低会报错，需切换测试通道安装
- **操作**：

    1. 若已安装旧版：插件列表右上角齿轮 → 插件 → 卸载`CheatDeck`
    2. 通用设置 → 商店通道切换为「测试」→ 搜索安装`CheatDeck`
    3. 安装完成后切回「默认」通道 → 打开无报错
    
### 功耗控制插件：SimpleDeckyTDP
- **下载地址**：[https://github.com/aarron-lee/SimpleDeckyTDP](https://github.com/aarron-lee/SimpleDeckyTDP)
- **安装**：
    1. 桌面模式下载`SimpleDeckyTDP.zip` → 返回游戏模式
    2. 插件列表设置 → 开发者模式 → 浏览文件 → 选择安装包安装
- **关键设置**：

|选项|推荐设置|说明|
|---|---|---|
|每个游戏单独配置|开启|自动保存不同游戏的 TDP 设置|
|功耗限制（TDP）|按需调整（SteamDeck 最大 15W，ROG 建议 30W）|数值越低续航越长，越高性能越强|
|CPU 睿频加速|开启|提升 CPU 瞬时性能|
|SMT 超线程|开启|提升多任务 / 游戏性能|
|CPU/GPU 功耗偏好|按游戏调整|优先 CPU 或 GPU|
|插电 / 离电不同配置|按需开启|分场景优化功耗|

## 进阶工具
### 1. 风灵月影修改器
- **官网**：[https://flingtrainer.com/](https://flingtrainer.com/)
- **操作步骤**：
    1. 桌面模式 → SteamOS 工具箱安装浏览器（推荐 Chrome）
    2. 浏览器访问官网 → 搜索游戏英文名下载对应修改器
    3. 新建文件夹（如「文档 / 风灵月影」）存放修改器
    4. 游戏模式 → 选中游戏 → 设置 → CheatDeck → 启用修改器 + 设置修改器路径 → 保存
    5. 进入游戏按菜单键 → 调出修改器，触屏操作调整数值
    6. 若修改器被遮挡：设置 → 显示 → 关闭自动缩放 → 手动调整字体大小
### 2. 汉化版小黄鸭（Lossless Scaling）
- **功能**：提升游戏帧数（支持 2 倍 FPS 倍数）
- **安装步骤**：
    1. 游戏模式 → 菜单 → 商店 → 搜索`lossless`（不勾选兼容）→ 安装（双系统需装在内部驱动器）
    2. 切换到桌面模式 → SteamOS 工具箱输入汉化版序号 → 回车安装（感谢 B 站大佬 MusTangGD 汉化）
    3. 游戏模式 → 插件列表打开小黄鸭 → 安装 → 加号设置 FPS 倍数为 2 倍 + 勾选性能模式
    4. 游戏设置 → CheatDeck → 高级选项 → 打开无损缩放
    5. 闪电图标可打开 / 切换性能监控窗口
- **注意**：每个游戏需单独设置一次才生效
---
## 总结
1. 插件商店是核心入口，系统更新后需用最新命令重装，图标缺失重启即可解决；
2. CheatDeck 需切换测试通道安装，小黄鸭、风灵月影可叠加使用提升游戏体验。
