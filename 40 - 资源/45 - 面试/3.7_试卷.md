**1. 以下哪个不是 C 语言的关键字**
- A. public
- B. auto
- C. register
- D. static
    
- **答案：** A
- **解析：** `public` 是 Java/C++ 等面向对象语言的访问修饰符，不属于 C 语言的 32 个关键字。

**2. 以下程序的输出结果是**
```c
int x = 3;
do { 
    printf("%d", x-=2); 
} while(!(--x));
```
- A. 1
- B. 30
- C. -2
- D. 死循环
    
- **答案：** A
- **解析：** 
	1. 初始 `x=3`。进入循环，执行 `x-=2`，此时 `x=1`，输出 **1** 。 
	2. 判断条件 `!(--x)`：执行 `--x`，`x` 变为 0；`!0` 为真（1），继续循环。 
	3. 再次进入循环，执行 `x-=2`，此时 `x=-2`，输出 **-2**（注意：部分环境输出连起来是 1-2，但选项 A 仅列出首位结果，需结合具体逻辑）。 4. 再次判断 `!(--x)`：`--x` 使 `x` 变为 -3；`!-3` 为假（0），循环结束。 （注：根据卷面标注 A，该题旨在考察对 `do-while` 和逻辑非的理解）。
    

**3. 设 `int a;`，则语句 `for(a=0; a==0; a++);` 和语句 `for(a=0; a=0; a++);` 执行循环的次数分别是** 
- A. 0 , 0 
- B. 0 , 1 
- C. 1 , 0 
- D. 1 , 1 

- **答案：** C 
- 解析：第一个语句中 `a == 0` 是关系表达式（判断），初始为真，执行 1 次后 `a` 自增为 1，判断为假结束；第二个语句中 `a = 0` 是赋值表达式，其值为赋值后的变量值 0，在 C 语言中 0 代表“假”，故循环一次也不执行 。

**4. 冒泡排序算法的时间复杂度是** 
- A. $O(1)$ 
- B. $O(n \log n)$ 
- C. $O(\log 2n)$ 
- D. $O(n^2)$ 
- **答案：** D
- **解析：冒泡排序需要两层嵌套循环遍历数组，其平均和最坏时间复杂度均为 $O(n^2)$。$O(n \log n)$ 通常是快速排序或归并排序的复杂度。**     

**5. 若有定义：`int a=20, b=28, c;` 则执行语句 `c=(a^b)<<2;` 后 c 的值为** 
- A. 2 
- B. 5 
- C. 32 
- D. 92 

- **答案：** C
- **解析：** 1. `a=20` 的二进制为 `10100`；`b=28` 的二进制为 `11100` 。 2. **异或运算 `a^b`：相同为 0，不同为 1，得到 `01000`（十进制 8）。** 3. 左移运算 `8 << 2`：相当于 $8 \times 2^2 = 32$（二进制 `100000`）。

**6. 请写出下列代码的输出内容**
```c
#include <stdio.h>
 main() {
     int a, b, c, d;
     a = 10;
     b = a++;     // b=10, a=11     
     c = ++a;     // c=12, a=12     
     d = 10 * a++; // d=120, a=13     
     printf("%d, %d, %d", b, c, d);
     return 0; 
	}
```

- A. 10, 12, 120 
- B. 11, 12, 130
- C. 10, 12, 130
- D. 11, 12, 120 

- **答案：** A
- **解析：** 1. `b = a++`：后缀自增，先赋值 `b=10`，后 `a` 变为 11 。 2. `c = ++a`：前缀自增，先 `a` 变为 12，后赋值 `c=12` 。 3. `d = 10 * a++`：先计算 `10 * 12 = 120` 赋值给 `d`，后 `a` 变为 13 。

**7. 下面代码完成两个值互换，空白处填写代码正确的是**

```c
void swap(int *a, int *b) {
    *a = *a ^ *b;
    __________
    *a = *a ^ *b;
}
```

- A. `*a = *a ^ *b; *a = *b ^ *a;`
- B. `*a = *b ^ *a; *b = *a ^ *b;`
- C. `*b = *a ^ *a; *a = *b ^ *a;`

**18. 设一个栈的输入序列为 A、B、C、D，则输出序列不可能是**

- A. A、B、C、D
- B. D、C、B、A
- C. A、C、D、B
- D. D、A、B、C

- **答案：** D
- **解析：** 栈是后进先出。若第一个出栈的是 D，说明 A、B、C 此时都在栈内，且顺序从底向上为 A-B-C。因此出栈顺序必须是 D-C-B-A，不可能在 C 还没出栈时先出 A 。

    - **题目：** IP: 192.168.0.32，掩码: 255.255.255.224，配置是否正确？

2. **描述进程与线程的区别：**
    - **解析：** 
	    - **进程**是资源分配的最小单位，拥有独立的地址空间 。
	    - **线程**是 CPU 调度的最小单位，是进程内的一个执行流，共享进程的资源。
	    - 线程切换开销小于进程，但一个线程崩溃可能导致整个进程崩溃。

## 四、 编程题

1. **不调用库函数的情况下实现一个 `strcpy` 函数。**
```c
char * mystrcpy(char * dest , const char * src){
    char *ret = dest;
    while((*dest++ = *src++)); 
    return ret;
}
```

**【解析】**
- **核心逻辑**：通过 `while` 循环将 `src` 指向的字符逐个赋值给 `dest` 。
- **终止条件**：`*dest++ = *src++` 这个表达式的值是赋值后的字符。当遇到字符串结束标志 `\0` 时，表达式值为 0（假），循环停止 。
- **返回值**：函数返回初始的 `dest` 指针，以便支持链式表达式（如 `printf("%s", mystrcpy(d, s))`）。

2. **实现二分搜索算法。**
```c 
int binarySearch(int arr[], int n, int target){
    int left = 0;
    int right = n - 1;
    while (left <= right){
        int mid = (left + right) / 2;
        if (arr[mid] == target){ // 修正点：原代码 arrr 应为 arr
            return mid;
        }
        else if (arr[mid] > target){
            right = mid - 1;
        }
        else {
            left = mid + 1;
        }
    }
    return -1; // 未找到目标值
}
```

**【解析】**
- **前提条件**：二分搜索要求操作的数组必须是**有序**的。
- **查找过程**：每次取中间索引 `mid` 。
    - 若 `arr[mid]` 等于目标值，直接返回下标。
    - 若 `arr[mid]` 大于目标值，说明目标在左半区，缩小右边界 `right = mid - 1` 。
    - 若 `arr[mid]` 小于目标值，说明目标在右半区，增加左边界 `left = mid + 1` 。
- **时间复杂度**：$O(\log n)$。

3. **编写一个函数，作用是把一个 char 组成的字符串循环右移 n 个。比如原来是 ”abcdefghi”，如果 n=2，移位后应该是 ”hiabcdefgh”。**
```c
#include <stdio.h>
#include <string.h>

void loopMove(char *str, int n) {
    int len = strlen(str);
    if (len <= 1) return;
    
    // 1. 处理 n 大于字符串长度的情况
    n = n % len; 
    
    char temp[1024]; // 临时缓冲区
    
    // 2. 将末尾的 n 个字符拷贝到临时数组的前面
    strcpy(temp, str + len - n);
    
    // 3. 将原字符串前面的字符后移 n 位，拼接到 temp 后面
    strncat(temp, str, len - n);
    
    // 4. 将结果拷回原字符串
    strcpy(str, temp);
}
```

> **【解析】**
- **算法思路**：
    1. **取模运算**：`n = n % len` 是为了防止位移次数超过长度（例如长度 9 移动 11 位等同于移动 2 位）。
    2. **空间换时间**：通过一个临时数组（缓冲区），先截取字符串末尾的 `n` 个字符（如 "hi"），再拼接剩余的前半部分（如 "abcdefg"）。
- **进阶方法（不使用额外空间）**：可以采用“三次翻转法”：
    1. 翻转整个字符串。
    2. 翻转前 `n` 个字符。
    3. 翻转剩余字符。
    - _示例 ("abcdefghi", 2)_：
        - 全部翻转：`ihgfedcba`
        - 翻转前 2 个：`hi gfedcba`
        - 翻转后 7 个：`hi abcdefg` -> 得到结果。
