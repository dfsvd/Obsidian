本篇文章基于arch Linux下的配置 fifcitx 5 的中文输入法配置
## 雾凇拼音
### 安装需要的包
```sh
sudo pacman -S fcitx5-im fcitx5-rime rime-ice-pinyin-git
```
`fcitx5-im` 包含了fcitx5的基本包

`fcitx5-rime`是输入法引擎

`rime-ice-pinyin-git` 雾凇拼音输入法（这个包在archlinuxcn）

### 编辑配置文件启动 rime 雾凇拼音
```sh
mkdir -p ~/.local/share/fcitx5/rime
nvim ~/.local/share/fcitx5/rime/default.custom.yaml 
```
添加以下内容
```yaml
    patch:
      # 这里的 rime_ice_suggestion 为雾凇方案的默认预设
      __include: rime_ice_suggestion:/
```
### 编辑环境变量
```sh
sudo vim /etc/environment
```
gnome 与 kde 配置文件有所不同
- gnome
```txt
XIM="fcitx"
GTK_IM_MODULE=fcitx
QT_IM_MODULE=fcitx
XMODIFIERS=@im=fcitx
XDG_CURRENT_DESKTOP=GNOME
```
`GTK_IM_MODULE=fcitx QT_IM_MODULE=fcitx XMODIFIERS=@im=fcitx`这三个是最主要的环境变量
`XDG_CURRENT_DESKTOP=GNOME` 这一项可以解决吞字问题，建议设置
- kde
```txt
XMODIFIERS=@im=fcitx
```


### 关闭Emoji（可选）
> *假设您使用的是全拼方案 (rime_ice)*
#### 确定雾凇拼音方案文件

您使用的雾凇拼音方案是 **全拼** (`rime_ice`) 还是 **小鹤双拼** (`double_pinyin_flypy`)？
1. **如果您使用全拼方案（rime_ice）：** 您需要修改或创建文件：`~/.local/share/fcitx5/rime/rime_ice.custom.yaml`
2. **如果您使用小鹤双拼方案（double_pinyin_flypy）：** 您需要修改或创建文件：`~/.local/share/fcitx5/rime/double_pinyin_flypy.custom.yaml`
#### 关闭 Emoji 输入
这里以**全拼方案**（`rime_ice.custom.yaml`）为例进行操作。如果您使用双拼，请将文件名替换为 `double_pinyin_flypy.custom.yaml`。
1. **打开或创建自定义配置文件：**
    ```sh
    nvim ~/.local/share/fcitx5/rime/rime_ice.custom.yaml
    ```
    _如果您没有此文件，请创建它。
2. **添加或修改以下内容：**
>  `emoji` 是 `switches` 列表中的**第四个**元素（索引为 `3`）。`reset: 0` 表示默认状态为关闭，且下次将记住状态。

 ```YAML
    patch:
      # 关闭 Emoji
      "switches/@3/reset": 0
 ```

3. **保存并关闭文件**
nvim 输入以下内容 `：wq` 保存
