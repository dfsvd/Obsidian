# Arch Linux & Windows 双系统蓝牙共用指南

本文档为解决双系统切换时，蓝牙耳机（如 Sony WH-1000XM4）需要反复配对的问题。
**原理：** 提取 Windows 注册表生成的 LinkKey，覆盖 Linux 的配置，欺骗耳机认为两个系统是同一台主机。

## 准备工作
1. **Linux 配对：** 先在 Arch 下连接耳机，确保能用。
2. **Windows 配对：** 重启进 Windows 连接耳机（这是最后一次配对，耳机此时只认 Windows 的 Key）。
3. **回到 Linux：** 重启回 Arch（此时耳机连不上是正常的）。
4. **重要：** 确保 Windows 已关闭“快速启动” (Fast Startup)，否则 Linux 无法挂载 C 盘。
## 获取 Windows 密钥
> 在 Arch 下操作
- **安装工具：**
```bash
sudo pacman -S chntpw
```
- **挂载 Windows C 盘：**
```bash
# 1. 查找 C 盘分区 (例如 /dev/nvme0n1p3)
lsblk
# 2. 创建挂载点
sudo mkdir -p /mnt/windows
# 3. 挂载
sudo mount /dev/nvme0n1p3 /mnt/windows
```
- **提取密钥 (LinkKey)：**
```Bash
# 进入注册表目录
cd /mnt/windows/Windows/System32/config/
# 打开注册表编辑器
sudo chntpw -e SYSTEM
```
**在 chntpw 交互界面中输入：**
```Plaintext
> cd ControlSet001\Services\BTHPORT\Parameters\Keys
> ls                        # 查看本机蓝牙适配器 MAC
> cd <适配器MAC>             # 进入适配器目录
> ls                        # 查看设备列表，找到耳机 MAC
> hex <耳机MAC>              # 显示密钥，例如: hex 94db56cd3572
```
- **操作：** 复制显示的 16 字节十六进制数据。
- **处理：** 去掉空格，全部转大写，合并成 32 个字符。
## 3. 修改 Linux 配置
定位文件：
Windows 格式为小写无冒号 (aabb...)，Linux 文件夹为大写带冒号 (AA:BB...)。
```Bash
# 确认路径
sudo ls /var/lib/bluetooth/
# 修改目标耳机的 info 文件
sudo nvim /var/lib/bluetooth/<适配器MAC>/<耳机MAC>/info
```
替换密钥：
找到 \[LinkKey] 部分，将 Key= 后的值替换为从 Windows 提取的新值。
## 4. 生效验证
```Bash
sudo systemctl restart bluetooth
```

此时耳机应能自动连接。

### 实战示例

**设备信息：**
- **设备型号：** Sony WH-1000XM4
- **本机适配器 MAC：**
    - Win 注册表: `f47b0924c0a6`
    - Arch 路径: `F4:7B:09:24:C0:A6`
- **耳机 MAC：**
    - Win 注册表: `94db56cd3572`
    - Arch 路径: `94:DB:56:CD:35:72`
**提取与修改：**
- Windows 原始数据 (chntpw hex 输出)：
    A6 05 B2 5F BF D6 8F 0A E2 29 2F 34 93 EE DD 43
- 处理后的 LinkKey：
    A605B25FBFD68F0AE2292F3493EEDD43
配置文件修改位置：
/var/lib/bluetooth/F4:7B:09:24:C0:A6/94:DB:56:CD:35:72/info
**修改内容：**
```
[LinkKey]
Key=A605B25FBFD68F0AE2292F3493EEDD43
Type=4
PINLength=0
```
