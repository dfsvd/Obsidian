## 基础概念
**cJSON** 是一个基于 ANSI C (C89) 编写的、超轻量级的 JSON 解析器。如果说复杂的 XML 解析库是“重型机械”，那么 cJSON 就是一把精巧的**瑞士军刀**。
### 核心特性
- **极简主义 (Minimalist)**
    - 只有两个文件：`cJSON.c` (源码) 和 `cJSON.h` (头文件)。
    - 无第三方依赖，可以直接扔进项目里编译。
- **广泛兼容 (Portable)**
    - 使用标准 C 编写，几乎支持所有平台（包括资源受限的嵌入式设备）。
- **数据结构通用**
    - 采用**双向链表**来表示 JSON 的层级结构，逻辑清晰。
- **MIT 协议**
    - 完全开源、免费、可商用。

> **类比理解**： 如果 JSON 数据是一张**设计图纸**（文本），C 语言中的变量是**实物零件**，那么 cJSON 就是负责将图纸转为零件（解析），或将零件画成图纸（生成）的**翻译官**。
### 集成方法
通常有两种方式将 cJSON 引入项目：
1. **直接集成 (推荐)**：将 `cJSON.c` 和 `cJSON.h` 复制到项目源码目录，编译时带上即可（如 `gcc main.c cJSON.c -o app`）
	-  [cJSON.h](../../49%20-%20代码片段/cJSON.h)
	-  [cJSON.c](../../49%20-%20代码片段/cJSON.c)
2. CMake 管理：将 `cJSON.c` 和 `cJSON.h` 复制到项目下的 `external` 文件夹
	1. external 下创建文件夹 `cJSON`
	2. 将 `cJSON.c` 和 `cJSON.h` 复制到 `cJSON` 中，
	3. 在 external 创建（添加）CMakeLists.txt 写入以下内容
```CMakeLists
# cJSON库
# 1. 创建静态库
add_library(cjson STATIC cJSON/cJSON.c)

# 2. 设置头文件路径
target_include_directories(cjson PUBLIC cJSON)

# 3. cJSON 依赖数学库
target_link_libraries(cjson PRIVATE m)
```
3. **CMake 集成**：适用于大型项目，通过 `add_subdirectory` 或 `find_package` 引入。
    
## 核心数据结构
理解 `cJSON` 结构体是掌握该库的关键。它本质上是一个**树状的双向链表**

```c
typedef struct cJSON {
    struct cJSON *next;  // 指向同级下一个节点 (兄弟)
    struct cJSON *prev;  // 指向同级上一个节点 (兄弟)
    struct cJSON *child; // 指向子节点 (如果是对象或数组)

    int type;            // 数据类型 (数字、字符串、数组、对象等)

    char *valuestring;   // 存放字符串值
    int valueint;        // 存放整数值 (已废弃，建议忽略)
    double valuedouble;  // 存放数值 (整数和浮点数都存这)

    char *string;        // 键名 (Key)，如 {"name": "Gemini"} 中的 "name"
} cJSON;
```
- **链表机制**：`next` 和 `prev` 用于遍历同一个对象或数组中的元素。
- **层级机制**：`child` 用于进入下一层级（如数组内部或对象内部）。
- **类型判断**：不要直接判断 `type` 字段，应使用官方宏（如 `cJSON_IsString`）。
    
## 关键 API 接口
cJSON 的 API 主要分为解析（读）、构建（写）、数组操作、类型检查和辅助工具五大类。请务必注意内存管理相关的说明。
### 解析与读取 (Read)
#### `cJSON_Parse`
- **函数原型**：`cJSON *cJSON_Parse(const char *value);`
- **功能**：将一个 JSON 格式的字符串解析成一个 cJSON 对象树（内存中的结构体链表）。
- **参数**：
    - `value`：待解析的 JSON 字符串。
- **返回值**：
    - 成功：返回指向根节点的指针（`cJSON *`）。
    - 失败：返回 `NULL`。
- **案例**：
    ```c
    char *json_str = "{\"name\": \"Gemini\"}";
    cJSON *root = cJSON_Parse(json_str);
    if (root == NULL) { /* 处理错误 */ }
    ```
- **【重要】**：该函数返回的指针**必须**在最后通过 `cJSON_Delete()` 释放，否则会造成内存泄漏。
#### `cJSON_GetObjectItemCaseSensitive`
- **函数原型**：`cJSON *cJSON_GetObjectItemCaseSensitive(const cJSON * const object, const char * const string);`
- **功能**：从一个对象（Object）中查找指定键名（Key）的子节点。
- **参数**：
    - `object`：父对象节点。
    - `string`：要查找的键名字符串。
- **返回值**：
    - 成功：返回对应的子节点指针。
    - 失败（未找到）：返回 `NULL`。
- **案例**：
    ```c
    cJSON *name_node = cJSON_GetObjectItemCaseSensitive(root, "name");
    ```
- **【提示】**：该函数返回的指针是由父对象管理的，**千万不要**手动释放它，也不要对它调用 `cJSON_Delete`。
> [提示]：
> - 早期的 cJSON 作者为了方便在设计时忽略了大小写使用了 `cJSON_GetObjectItem` 来获取节点
> - 根据 JSON 标准 (RFC 8259)，对象中的键是**大小写敏感**的。为了修复这个问题并符合标准，cJSON 后来引入了 `CaseSensitive` 后缀的版本
> - 永远优先使用 `cJSON_GetObjectItemCaseSensitive`

### 构建与生成 (Write)
#### `cJSON_GetErrorPtr`
- **函数原型**：`const char *cJSON_GetErrorPtr(void);`
- **功能**：当 `cJSON_Parse` 失败时，获取出错位置的指针。
- **参数**：无。
- **返回值**：返回指向输入字符串中解析失败位置的指针。
- **案例**：
    ```c
    cJSON *root = cJSON_Parse(broken_json);
    if (!root) {
        printf("解析出错，错误位置在: %s\n", cJSON_GetErrorPtr());
    }
    ```
### 2. 构建与生成 (Write)
#### `cJSON_CreateObject` / `cJSON_CreateArray`
- **函数原型**：
    - `cJSON *cJSON_CreateObject(void);`
    - `cJSON *cJSON_CreateArray(void);`
- **功能**：创建一个空的 JSON 对象 `{}` 或数组 `[]`。
- **参数**：无。
- **返回值**：返回新创建的节点指针。
- **案例**：
    ```c
    cJSON *obj = cJSON_CreateObject();
    cJSON *arr = cJSON_CreateArray();
    ```
- **【注意】**：如果是作为根节点，使用完毕后需要 `cJSON_Delete()`；如果是作为子节点添加到其他对象中，则不需要单独释放。
#### `cJSON_AddItemToObject`
- **函数原型**：`void cJSON_AddItemToObject(cJSON *object, const char *string, cJSON *item);`
- **功能**：将一个节点添加到对象中，并指定键名。
- **参数**：
    - `object`：父对象。
    - `string`：键名。
    - `item`：要添加的子节点。
- **返回值**：无。
- **案例**：
    ```c
    cJSON *root = cJSON_CreateObject();
    cJSON *body = cJSON_CreateObject();
    cJSON_AddItemToObject(root, "body", body);
    ```
- **【重要】**：**所有权转移**！一旦调用此函数，`item` 的内存管理权就移交给了 `object`，`cJSON_Delete(root)` 时会自动释放 `body`，不可再手动释放 `body`。
#### `cJSON_Print`
- **函数原型**：`char *cJSON_Print(const cJSON *item);`
- **功能**：将 cJSON 对象树打印成格式化（带换行和缩进）的字符串。
- **参数**：
    - `item`：要打印的 cJSON 节点（通常是根节点）。
- **返回值**：返回一个动态分配的字符串指针。
- **案例**：
    ```c
    char *str = cJSON_Print(root);
    printf("%s", str);
    free(str); // 必须释放
    ```
- **【重要】**：该函数内部使用了 `malloc`，返回的字符串**必须使用 `free()` 释放**。若需要无格式压缩字符串，请使用 `cJSON_PrintUnformatted`。
### 3. 快捷构建宏 (Helper Macros)
这些宏封装了“创建节点”+“添加到对象”两个步骤，极大简化代码。
#### `cJSON_AddStringToObject` / `cJSON_AddNumberToObject` / `cJSON_AddBoolToObject`
- **函数原型**（宏）：
    - `cJSON_AddStringToObject(object, name, s)`
    - `cJSON_AddNumberToObject(object, name, n)`
    - `cJSON_AddBoolToObject(object, name, b)`
- **功能**：创建一个指定类型的值并添加到对象中。
- **参数**：
    - `object`：父对象。
    - `name`：键名。
    - `s`/`n`/`b`：对应类型的数值（字符串/数字/布尔值）。
- **返回值**：返回新创建的节点指针（通常忽略）。
- **案例**：
    ```c
    cJSON_AddStringToObject(root, "name", "Gemini");
    cJSON_AddNumberToObject(root, "age", 2);
    cJSON_AddBoolToObject(root, "is_ai", 1);
    ```
### 数组操作 (Array Operations)
#### `cJSON_AddItemToArray`
- **函数原型**：`void cJSON_AddItemToArray(cJSON *array, cJSON *item);`
- **功能**：将一个节点添加到数组的末尾。
- **参数**：
    - `array`：父数组节点。
    - `item`：要添加的元素节点。
- **返回值**：无。
- **案例**：
    ```c
    cJSON *arr = cJSON_CreateArray();
    cJSON *num = cJSON_CreateNumber(100);
    cJSON_AddItemToArray(arr, num);
    ```
- **【注意】**：同样发生**所有权转移**，不要手动释放 `item`。
#### `cJSON_GetArraySize`
- **函数原型**：`int cJSON_GetArraySize(const cJSON *array);`
- **功能**：获取数组中的元素个数。
- **参数**：`array`：数组节点。
- **返回值**：数组长度（整数）。
- **案例**：
    ```c
    int count = cJSON_GetArraySize(resolutions_arr);
    ```
#### `cJSON_ArrayForEach` (宏)
- **函数原型**：`cJSON_ArrayForEach(element, array)`
- **功能**：高效遍历数组或对象。
- **参数**：
    - `element`：`cJSON *` 类型的迭代器指针（需提前声明）。
    - `array`：要遍历的数组/对象根节点。
- **返回值**：无（这是个循环控制宏）。
- **案例**：
    ```c
    cJSON *item = NULL;
    cJSON_ArrayForEach(item, arr) {
        printf("%f\n", item->valuedouble);
    }
    ```
- **【提示】**：这是最推荐的遍历方式，底层是链表操作，效率为 O(n)。
### 5. 类型判断与内存管理
#### `cJSON_Is...` 系列宏
- **函数原型**：
    - `cJSON_IsNumber(const cJSON *item)`
    - `cJSON_IsString(const cJSON *item)`
    - `cJSON_IsArray(const cJSON *item)`
    - ... (Bool, Object, Null 等)
- **功能**：判断节点是否为指定的数据类型。
- **参数**：`item`：待检查的节点。
- **返回值**：是返回 `1` (true)，否返回 `0` (false)。
- **案例**：
    ```c
    if (cJSON_IsString(node)) {
        printf("%s", node->valuestring);
    }
    ```
- **【注意】**：严禁直接使用 `node->type == cJSON_Number` 这种写法，宏处理了更多边界情况。
#### `cJSON_Delete`
- **函数原型**：`void cJSON_Delete(cJSON *item);`
- **功能**：删除 cJSON 实体并释放内存。
- **参数**：`item`：要删除的节点（通常是根节点）。
- **返回值**：无。
- **案例**：
    ```c
    cJSON_Delete(root);
    ```
- **【重要】**：该函数是**递归**的，它会删除当前节点、它的所有子节点（child）以及它的所有子节点的子节点。通常一个 JSON 树只需要对根节点调用一次即可。
## 示例代码
### 构建 (生成 JSON)
**目标**：创建一个描述显示器的 JSON。

```json
{
    "name": "Awesome 4K",
    "resolutions": [
        { "width": 1920, "height": 1080 }
    ]
}
```
**代码实现**：
```c
#include <stdio.h>
#include <stdlib.h>
#include "cJSON.h"

int main() {
    // 1. 创建根对象
    cJSON *monitor = cJSON_CreateObject();
    
    // 2. 添加基础字段
    // 助手函数：自动创建字符串节点并添加
    cJSON_AddStringToObject(monitor, "name", "Awesome 4K");

    // 3. 创建数组并添加
    cJSON *resolutions = cJSON_CreateArray();
    cJSON_AddItemToObject(monitor, "resolutions", resolutions);

    // 4. 创建数组内的对象
    cJSON *res1 = cJSON_CreateObject();
    cJSON_AddNumberToObject(res1, "width", 1920);
    cJSON_AddNumberToObject(res1, "height", 1080);
    
    // 将对象加入数组
    // 注意：res1 的内存管理权现在归 resolutions 所有
    cJSON_AddItemToArray(resolutions, res1);

    // 5. 打印生成字符串
    char *json_str = cJSON_Print(monitor);
    printf("生成的 JSON:\n%s\n", json_str);

    // 6. 清理内存 (关键步骤)
    cJSON_Delete(monitor); // 释放整个树结构
    free(json_str);        // 释放 Print 生成的字符串

    return 0;
}
```
### 场景二：解析 (读取 JSON)
**目标**：解析上述 JSON 字符串，判断是否包含 1080p 分辨率。
**代码实现**：
```c
#include <stdio.h>
#include <stdlib.h>
#include "cJSON.h"

void parse_monitor(const char *json_str) {
    // 1. 解析字符串 -> 树结构
    cJSON *monitor = cJSON_Parse(json_str);
    if (monitor == NULL) {
        const char *error_ptr = cJSON_GetErrorPtr();
        if (error_ptr != NULL) fprintf(stderr, "解析错误位置: %s\n", error_ptr);
        return;
    }

    // 2. 读取 "name"
    cJSON *name = cJSON_GetObjectItemCaseSensitive(monitor, "name");
    if (cJSON_IsString(name) && (name->valuestring != NULL)) {
        printf("显示器型号: %s\n", name->valuestring);
    }

    // 3. 遍历数组
    cJSON *resolutions = cJSON_GetObjectItemCaseSensitive(monitor, "resolutions");
    cJSON *item = NULL;

    // 使用 cJSON 专用宏进行安全遍历
    cJSON_ArrayForEach(item, resolutions) {
        cJSON *w = cJSON_GetObjectItemCaseSensitive(item, "width");
        cJSON *h = cJSON_GetObjectItemCaseSensitive(item, "height");

        if (cJSON_IsNumber(w) && cJSON_IsNumber(h)) {
            // 注意：cJSON 的数字统一存储为 double
            if (w->valuedouble == 1920 && h->valuedouble == 1080) {
                printf(">> 发现 1080p 配置！\n");
            }
        }
    }

    // 4. 释放内存
    cJSON_Delete(monitor); // 只需要释放根节点
}

int main() {
    char *json = "{\"name\":\"Awesome 4K\",\"resolutions\":[{\"width\":1920,\"height\":1080}]}";
    parse_monitor(json);
    return 0;
}
```



## 避坑指南 (Analysis & Pitfalls)

在使用 cJSON 开发时，**内存管理**是最大的痛点，请务必遵循以下规则：

### 1. 内存管理三大定律

- **定律一**：凡是 `cJSON_Create...` 或 `cJSON_Parse` 出来的**根节点**，最终必须调用 `cJSON_Delete()`。
    
- **定律二**：凡是 `cJSON_Print...` 返回的 `char*` 指针，最终必须调用 `free()`。
    
- **定律三**：一旦调用 `cJSON_AddItemToObject` 或 `cJSON_AddItemToArray`，子对象的**所有权 (Ownership)** 就转移给了父对象。
    
    - _错误做法_：添加后，手动 `cJSON_Delete(sub_item)`。 -> **导致程序崩溃 (Double Free)**。
        
    - _正确做法_：只 `cJSON_Delete(root)`，它会自动递归清理所有子节点。
        

### 2. 浮点数陷阱

cJSON 中**没有纯整型**，所有数字底层都用 `double` 存储。

- 读取时：虽然有 `valueint` 字段，但建议优先读取 `valuedouble` 并根据需要强转，防止大整数溢出。
    

### 3. 线程安全

- `cJSON` 默认情况下是线程安全的（只要你不修改全局钩子）。
    
- 但在多线程环境中使用 `cJSON_GetErrorPtr()` 可能会有竞争风险，建议在多线程中仅处理局部变量。

## 思考与练习

**思考题**： 为什么 cJSON 的 `type` 检查推荐使用宏（如 `cJSON_IsNumber`）而不是直接 `if (node->type == cJSON_Number)`？

- **答案**：因为 `type` 字段不仅包含类型信息，还可能包含标志位（如 `cJSON_IsReference`）。宏函数使用了位运算来屏蔽干扰位，更加健壮和准确。
