## 系统定时器 SysTick 与精准延时实现全解析

在嵌入式开发中，精准的延时控制和系统心跳（Tick）是两个不可或缺的基础功能对于 STM32 开发者而言，直接使用 Cortex-M 内核自带的 **SysTick（系统滴答定时器）** 是实现这些功能的最佳方案
不同于芯片厂商（如 ST）设计的外设（如 TIM1, TIM2），SysTick 是 Cortex-M 内核（M3/M4等）的一个**内嵌外设**这意味着无论你使用 STM32、NXP 还是其他基于 Cortex-M 的芯片，SysTick 的工作原理和代码移植性几乎是一致的
本文将从硬件原理、寄存器操作、中断配置到轮询模式的精准延时代码实现，进行全方位的深度解析

---
### SysTick 基础
#### 基本简介
SysTick 是一个 **24位** 的 **向下递减** 计数器
- **24位**：意味着它的最大计数值为 $2^{24} - 1 = 16,777,215$
- **向下递减**：计数器从重装载值（Reload Value）开始，每个时钟周期减 1，直到减为 0
- **工作流程**：当计数器减到 0 时，它会根据配置产生中断请求（异常），并自动从重装载寄存器中重新读取数值，开始下一轮计数
![|451](images/007_%20系统定时器（精准延时）/file-20260104231031328.jpg)
#### 系统定时器作用
SysTick 的应用场景主要取决于系统是否运行操作系统：
1. **裸机环境（No OS）**：通常只用于实现 **精准延时**（us/ms 级阻塞延时）
2. **操作系统环境（RTOS）**：如 UCOS、FreeRTOS、RT-Thread 等，SysTick 被用作系统的 **时基（Time Base）**，提供精准的定时中断（心跳），用于任务调度和时间片管理
#### 时钟源与频率
SysTick 的计数速度取决于其输入时钟源在 STM32F4 等系列中，RCC 向 Cortex 系统定时器馈送 **8分频的 AHB 时钟 (HCLK/8)**，但也允许配置为直接使用 **内核时钟 (HCLK)**
具体配置在 `SysTick->CTRL` 寄存器中进行以 STM32F407 为例：
- **HCLK (内核时钟)**：168 MHz
- **HCLK/8 (外部参考)**：$168 \div 8 = 21$ MHz
**频率与周期的关系**：
- **频率 ($f$)**：物质在 1s 内完成周期性变化的次数
- **周期 ($T$)**：$T = 1/f$
    
> 应用示例：
>
> 如果选择 168MHz 作为时钟源，计数器减 1 代表的时间为 $\frac{1}{168000000}$ 秒
> 如果要延时 1 微秒 ($1\mu s$)，则需要计数的次数为：$168 \text{ MHz} \times 1 \mu s = 168$ 次

### 关键寄存器
要操作 SysTick，必须掌握以下三个核心寄存器
#### 控制和状态寄存器 (SysTick->CTRL)

这是 SysTick 的控制枢纽，用于启动定时器、选择时钟源和使能中断

| **位 (Bit)** | **名称**        | **类型** | **描述** | **关键点**                                                    |
| ----------- | ------------- | ------ | ------ | ---------------------------------------------------------- |
| **16**      | **COUNTFLAG** | R      | 计数标志位  | 当计数器减到0时，该位被置为1**读取该位或写入 VAL 寄存器会自动清零**                  |
| **2**       | **CLKSOURCE** | R/W    | 时钟源选择  | **0**: 外部参考时钟 (STCLK, HCLK/8)<br>**1**: 内核时钟 (FCLK, HCLK) |
| **1**       | **TICKINT**   | R/W    | 中断使能   | **1**: 计数器归零时产生中断<br>**0**: 不产生中断                         |
| **0**       | **ENABLE**    | R/W    | 使能位    | **1**: 启动 SysTick <br>**0**: 关闭 SysTick                   |

#### 重装载值寄存器 (SysTick->LOAD)

用于存放计数器的初值当计数器减到 0 时，会自动将该寄存器的值重装载到当前计数值寄存器
- **位宽**：24位 (Bit 0-23)
- **注意**：因为计数包含 0，所以如果需要 N 个周期的延时，重装载值通常设为 $N-1$（但在某些轮询实现中，为了简化计算常设为 N，误差极小）
#### 当前数值寄存器 (SysTick->VAL)
实时记录当前计数器的数值
- **读取**：返回当前计数值
- **写入**：**写入任意值都会将当前计数值清零**，并且同时清除 CTRL 寄存器中的 COUNTFLAG 标志位

### 中断定时 (SysTick_Config)

在需要固定周期执行任务（如 LED 闪烁、按键扫描）时，可以使用中断模式CMSIS 标准库提供了一个便捷函数 `SysTick_Config`
#### 函数分析
此函数位于 core_cm4.h 中，用于初始化 SysTick 并开启中断

```c
/**
 * @brief  初始化 SysTick
 * @param  ticks: 两次中断之间的计数值 (Ticks)
 * @return 0: 成功, 1: 失败
 */
__STATIC_INLINE uint32_t SysTick_Config(uint32_t ticks)
{
    // 检查 ticks 是否超过 24位 最大值
    if ((ticks - 1UL) > SysTick_LOAD_RELOAD_Msk) return (1UL); 

    SysTick->LOAD  = (uint32_t)(ticks - 1UL);      // 设置重装载值 [cite: 97]
    NVIC_SetPriority (SysTick_IRQn, ...);          // 设置中断优先级
    SysTick->VAL   = 0UL;                          // 清空当前值
    // 设置时钟源为内核时钟，并开启中断和定时器
    SysTick->CTRL  = SysTick_CTRL_CLKSOURCE_Msk | 
                     SysTick_CTRL_TICKINT_Msk   | 
                     SysTick_CTRL_ENABLE_Msk;      
    return (0UL); 
}
```
#### 最大定时时间的局限性
使用 `SysTick_Config` 时，必须注意 24 位计数器的溢出问题
- **公式**：$T_{max} = \frac{2^{24}}{f_{clk}}$

- 以 168MHz 为例：
    最大定时时间 $T_{max} = \frac{16,777,216}{168,000,000} \approx 99.86 \text{ ms}$
![](images/007_%20系统定时器（精准延时）/file-20260104231031314.jpg)

> **测试结论**：
> - 配置 `SystemCoreClock/1000` (1ms)：**成功**
> - 配置 `SystemCoreClock/10` (100ms)：**失败**（超过了 99.86ms 的上限）
> - 配置 `SystemCoreClock/11` (~90.9ms)：**成功**
>     

**总结**：如果使用 168MHz 时钟，单次中断周期不能超过 99.86ms

### 精准延时 (轮询模式)

在裸机开发中，为了生成微秒 (us) 或毫秒 (ms) 级的阻塞延时，通常采用 **轮询模式 (Polling Mode)**这种方式不需要开启中断，而是通过程序查询 `COUNTFLAG` 标志位来判断时间是否到达
#### 配置步骤
根据《Cortex M3与M4权威指南》，直接操作寄存器的推荐步骤如下 ：
1. **Reload**：向 `SysTick->LOAD` 写入目标计数值
2. **Clear**：向 `SysTick->VAL` 写入 0，复位计数器和标志
3. **Enable**：写入 `SysTick->CTRL` 启动定时器
4. **Wait**：轮询 `SysTick->CTRL` 寄存器，直到 Bit 16 (COUNTFLAG) 变 1

#### 完整代码实现

以下代码封装了时钟源配置、微秒延时和毫秒延时函数
##### 初始化函数
为了增加灵活性，支持选择 168MHz (内核时钟) 或 21MHz (外部参考时钟)
```c
static uint8_t  sysclk_nus      = 0;  // 1us 的计数值
static uint32_t sysclk_nms      = 0;  // 1ms 的计数值
static uint8_t  sysclk_clh_flag = 0;  // CTRL 寄存器配置缓存

/**
 * @brief  系统定时器初始化
 * @param  sysclk: 168 (内核时钟) 或 21 (外部参考时钟)
 */
int8_t DELAY_SysTickInit(uint8_t sysclk)
{
    if(sysclk == 168)
    {
        sysclk_nus      = 168;           // 1us 需要 168 个脉冲
        sysclk_nms      = 168000;        // 1ms 需要 168000 个脉冲
        sysclk_clh_flag = 5;             // Binary: 0101 (Bit2=1使用内核时钟, Bit0=1使能) [cite: 109, 128]
    }
    else if(sysclk == 21)
    {
        sysclk_nus      = 21;
        sysclk_nms      = 21000;
        sysclk_clh_flag = 1;             // Binary: 0001 (Bit2=0使用外部时钟, Bit0=1使能) [cite: 128]
    }
    else
    {
        return -1; // 参数错误
    }
    return 0;
}
```

##### 微秒级精准延时 (delay_us)
该函数加入了对“定时器意外关闭”的安全检查，防止程序死锁
```c
/**
 * @brief  精准延时 nus
 */
int8_t delay_us(uint32_t nus)
{
    uint32_t t = nus;
    uint32_t temp = 0;

    // 循环次数，这里采用简单的多次计数实现（也可直接计算总Ticks，但要注意24位溢出）
    while(t--)
    {
        SysTick->CTRL = 0;                  // 1. 关闭定时器 
        SysTick->LOAD = sysclk_nus - 1;     // 2. 填入重装载值 
        SysTick->VAL  = 0;                  // 3. 清空计数器 
        SysTick->CTRL = sysclk_clh_flag;    // 4. 启动定时器 

        while(1)
        {
            temp = SysTick->CTRL;

            // 检测 COUNTFLAG (Bit 16) 是否置位
            if(temp & 0x00010000) 
                break; // 时间到

            // 【重要】检查系统定时器是否意外关闭 (Bit 0)
            // 如果外部中断或其他程序意外关闭了 SysTick，此检查防止死循环
            if( (temp & 0x1) == 0 ) 
                return -1; 
        }
        
        SysTick->CTRL = 0; // 关闭定时器
    }
    return 0;
}
```

##### 毫秒级精准延时 (delay_ms)

原理与微秒延时相同，只是重装载值不同
```c
/**
 * @brief  精准延时 nms
 */
int8_t delay_ms(uint32_t nms)
{
    uint32_t t = nms;
    uint32_t temp = 0;

    while(t--)
    {
        SysTick->CTRL = 0;
        SysTick->LOAD = sysclk_nms - 1;     // 装载 1ms 的计数值
        SysTick->VAL  = 0;
        SysTick->CTRL = sysclk_clh_flag;

        while(1)
        {
            temp = SysTick->CTRL;
            // 检测 COUNTFLAG
            if(temp & 0x00010000)
                break;
            // 意外关闭检测
            if( (temp & 0x1) == 0 )
                return -1;
        }
        SysTick->CTRL = 0;
    }
    return 0;
}
```
