#stm32
## 外设定时器基础
### 基本定义与核心本质
- **硬件定义**：定时器（Timer）是单片机内部用于设置等待时间，并在预设时间到达后执行特定操作的硬件外设。
- **计数方式**：其内部计数器支持灵活的计数方向，既可以向上计数（递增），也可以向下计数（递减）。
- **功能特征**：
    - **基本定时与计数**：实现精确的时间延迟或对外部事件进行计数。
    - **PWM 输出**：通过调节占空比和频率，实现灯光亮度控制、蜂鸣器音调调节以及电机速度控制 。
    - **脉冲捕获**：用于测量输入信号的频率或电平宽度，典型应用如红外信号捕获。
### 定时器资源分布与应用定位
STM32F407 芯片内部集成了 14 个硬件定时器，具体分布如下：

| **定时器类型**      | **具体编号**     | **挂载总线**     | **计数位数** | **功能特征与典型应用**                                     |
| -------------- | ------------ | ------------ | -------- | ------------------------------------------------- |
| **高级控制定时器**    | TIM1, TIM8   | APB2 (84MHz) | 16 位     | 具有高级 PWM 输出、带死区互补输出及捕获功能。主要用于**飞行器（四轴）**及复杂电机控制 。 |
| **通用定时器 (I)**  | TIM2 - TIM5  | APB1 (42MHz) | 16/32 位  | 具备 PWM 输出控制。常用于**舵机、LED、蜂鸣器**的驱动 。                |
| **通用定时器 (II)** | TIM9 - TIM14 | APB1/APB2    | 16 位     | 具备基本的定时及 PWM 输出控制功能。                              |
| **基本定时器**      | TIM6, TIM7   | APB1 (42MHz) | 16 位     | 仅具备单纯的定时功能。适用于**定时闹钟**或触发 DAC 转换。                 |

> [!tip]
> - **术语简称**：在程序开发和芯片手册中，**TIM** 是英文 **TIMER** 的缩写形式。
> - **引脚适配建议**：
>     - **TIM14 (通用)**：结构简单，适合单个引脚的 PWM 功能输出（如单一控制 LED 或蜂鸣器）
>     - **TIM1 (高级)**：具备多通道同步能力，适合多个引脚联动的 PWM 功能输出（如四轴飞行器的四个旋翼同步调速)

## 外设定时器时间的计算
### 定时器时钟频率的硬件自动计算机制

在 STM32F405xx/STM32F407xx 系列中，定时器的最终工作频率（TIMxCLK）并不是简单地等于外设总线（APB）的频率，而是由硬件根据 **RCC 时钟配置寄存器**中的 APB 预分频系数（Prescaler）自动计算得出的 。其核心逻辑遵循以下两个准则：
1. **准则一**：如果 APB 预分频器系数为 **1**，则定时器的时钟频率直接等于该 APB 域的频率。
2. **准则二**：如果 APB 预分频器系数 **大于 1**（例如 2、4、8、16），则定时器的时钟频率等于该 APB 域频率的 **2 倍**
![](images/008_%20外设定时器/file-20260104231033380%201.jpg)
#### 库函数源码背景
在标准库文件 `system_stm32f4xx.c` 的 `SetSysClock()` 函数中，系统默认配置通常如下：
- **SYSCLK (系统主频)**: 168MHz。
- **HCLK (AHB总线)**: 168MHz。
- **PCLK1 (APB1总线)**: $168MHz / 4 = 42MHz$。
- **PCLK2 (APB2总线)**: $168MHz / 2 = 84MHz$。
根据上述准则：
- **APB1 定时器频率 (TIM2-7, 12-14)**: 由于 APB1 分频为 4（不为 1），其时钟频率为 $42MHz \times 2 = 84MHz$
- **APB2 定时器频率 (TI1, 8-11)**: 由于 APB2 分频为 2（不为 1），其时钟频率为 $84MHz \times 2 = 168MHz$
---
### 定时器 3 (TIM3) 硬件时钟实战推导
![](images/008_%20外设定时器/file-20260104231033379.jpg)
以挂载在 APB1 总线上的通用定时器 TIM3 为例，其内部时钟生成的完整链路如下：
1. **源头**: $SYSCLK = 168MHz$。
2. **第一级**: $AHB / 1 = 168MHz$。
3. **第二级**: $APB1 / 4 = 42MHz$。
4. **硬件自动倍频**: 因为分频系数为 4（不等于 1），硬件自动执行 $\times 2$ 操作，最终得到 $TIM3CLK = 84MHz$。
---

### 定时参数配置 (500ms 案例)
若要实现 500ms（0.5秒）的中断触发，我们需要配置定时器单元的两个核心寄存器：预分频值（PSC）和自动重装载值（ARR/Period）
#### 配置参数：
- **TIM_Prescaler (一次分频)**: 设置为 `8400 - 1` 。
    - **原理**: $\frac{84,000,000Hz}{8400} = 10,000Hz$
    - 此时，定时器内部计数器每隔 $0.0001$ 秒（即 $0.1ms$）自增一次
- **TIM_Period (周期值/计数值)**: 设置为 `5000 - 1`
    - **原理**: 在 $10,000Hz$ 的驱动下计数 5000 次，耗时 $\frac{5000}{10000} = 0.5s = 500ms$
- **TIM_ClockDivision (二次分频)**: 设置为 `0`
    - STM32F407 内部对该外设暂无硬件二次分频需求
- **TIM_CounterMode (计数模式)**: `TIM_CounterMode_Up`
    - 采用向上计数模式，即从 0 计到 4999 后触发中断并归零
#### 代码实现
```c
TIM_TimeBaseStructure.TIM_Prescaler = 8400-1; // 预分频值(一次分频)
TIM_TimeBaseStructure.TIM_Period = 5000-1; // 周期
TIM_TimeBaseStructure.TIM_ClockDivision = 0; // 时钟分频(二次分频)
TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up; // 计数模式：从下往上计数 TIM_TimeBaseInit(TIM3, &TIM_TimeBaseStructure); // 写入配置好的外设信息到相应的寄存器中
```

#### 最大定时时间 (TMAX)
在计数频率保持 $10,000Hz$ 的前提下，由于通用定时器（如 TIM3）的自动重装载寄存器是 16 位的，其最大计数值为 $65535$。
- **计算公式**: $\frac{65535}{10000Hz} = 6.5535s$。
- **结论**: 在该频率下，单次定时器的最大溢出时间约为 $6.55s$。
---
> [!tip]
> - 在编写代码时，建议使用 `(频率/目标计频)-1` 的形式填入寄存器，以抵消硬件计数器从 0 开始计数的偏移；如频率为 ${10000Hz}$ 目标计频为 ${500ms}$
> - STM32F407无时钟分屏（二次分频）TIM_ClockDivision = 0 只需设置为 0

## 外设定时器库函数的说明和使用
### 实现定时器中断的编程代码思路
在 STM32F4 开发中，要实现一个完整的定时器中断功能，通常遵循以下严谨的逻辑步骤 ：
1. **环境初始化与时钟使能**：
    - 首先必须使能定时器对应的硬件时钟，这是外设工作的前提 。
2. **核心参数配置 (Time Base Unit)**：
    - **设置分频值 (Prescaler)**：决定计数器的跳动频率 。
    - **确定计数值 (Period/ARR)**：决定触发中断的时间周期 。
3. **中断与优先级配置**：
    - **开启更新中断 (Update Interrupt)**：允许定时器在计数溢出时触发中断信号 。
    - **配置 NVIC 中断优先级**：在嵌套向量中断控制器中设置定时器的优先级分组及具体优先级 。
4. **启动定时器**：
    - 正式使能定时器开始计数工作 。
5. **中断服务函数 (ISR) 编写**：
    - 在特定的中断向量入口编写业务逻辑代码 。
        

---

### 核心库函数 API
#### 定时器基本单位初始化函数
该函数用于根据结构体中的参数初始化定时器的基本单元（时基单元） 。
```c
/**
  * @brief  根据指定的参数初始化 TIMx 的时基单元
  * @param  TIMx: 选择定时器外设，x 可以是 1 到 14 
  * @param  TIM_TimeBaseInitStruct: 指向包含配置信息的结构体指针
  * @retval 无 
  */
void TIM_TimeBaseInit(TIM_TypeDef* TIMx, TIM_TimeBaseInitTypeDef* TIM_TimeBaseInitStruct)
```

**结构体说明：**
- `TIM_Prescaler`：预分频值。
- `TIM_Period`：自动重装载周期值（计数值）。
- `TIM_CounterMode`：计数模式（向上、向下等）。
- `TIM_ClockDivision`：时钟分频因子。
---
#### 定时器中断触发配置函数
该函数用于使能或禁止定时器特定的中断源
```c
/**
  * @brief  使能或禁止指定的 TIM 中断
  * @param  TIMx: 选择定时器外设，x 为 1 到 14
  * @param  TIM_IT: 指定要开启的中断源。常用取值如下：
  * 	@arg TIM_IT_Update: 计数器溢出更新中断
  * 	@arg TIM_IT_CC1~4: 捕获/比较通道 1 到 4 中断 
  * @param  NewState: 中断的新状态。可选值：ENABLE (开启) 或 DISABLE (关闭) 
  * @retval 无 
  */
void TIM_ITConfig(TIM_TypeDef* TIMx, uint16_t TIM_IT, FunctionalState NewState)
```

开发注意细节 ：
- 对于**基本定时器 (TIM6/7)**，仅能使用 `TIM_IT_Update` 。
- 对于 **TIM10/11/13/14**，仅支持使用 `TIM_IT_Update` 或 `TIM_IT_CC1` 。
- `TIM_IT_COM` 和 `TIM_IT_Break`（刹车中断）仅适用于**高级定时器 (TIM1/8)** 。

---
#### 定时器工作使能控制函数
该函数类似于外设的总开关，决定定时器是否开始计数 。
```c
/**
  * @brief  使能或禁止指定的 TIM 外设运行
  * @param  TIMx: 选择定时器外设，x 为 1 到 14
  * @param  NewState: 定时器的新状态。可选值：ENABLE (启动) 或 DISABLE (停止)
  * @retval 无
  */
void TIM_Cmd(TIM_TypeDef* TIMx, FunctionalState NewState)
```

---

> [!tip]
>  在实际开发中，务必先调用 `TIM_TimeBaseInit` 进行参数装载，最后再调用 `TIM_Cmd` 启动计数，以避免出现不可控的初始计时误差

## PWM 的概述
### 物理定义与核心本质
**PWM** 是 **Pulse Width Modulation** 的缩写，即**脉冲宽度调制** 。它是一种利用微处理器的数字输出来对模拟电路进行控制的非常有效的方法。
PWM 信号本质上是一种周期性的**方波信号**，其核心组成要素包括：
- **脉冲 (Pulse)**：即方波，主要由**频率 (Frequency)** 决定其每秒钟跳动的次数 。
- **宽度 (Width)**：指一个周期内高电平持续的时间 。
- **占空比 (Duty Cycle)**：这是 PWM 最核心的参数，指在一个周期内，**高电平持续时间**占**整个周期时间**的百分比 。
#### 占空比与输出关系示例：
- **占空比 25%**：高电平占 1/4 周期，低电平占 3/4 周期
![](images/008_%20外设定时器/file-20260104231033377.jpg)
- **占空比 50%**：高电平与低电平各占一半，输出平均电压为峰值的一半
![](images/008_%20外设定时器/file-20260104231033373.jpg)
- **占空比 75%**：高电平占 3/4 周期，输出能量较高
![](images/008_%20外设定时器/file-20260104231033372.jpg)
- **结论**：通过调节占空比，可以控制输出到负载的**平均能量**（如 LED 的亮度和电机的转速）
![](images/008_%20外设定时器/file-20260104231033371.jpg)
---
### PWM 调控的实际应用场景
在 STM32 开发中，PWM 被广泛应用于控制各种外设的状态：
1. **LED 亮度控制（呼吸灯效果）**：
    - **原理**：利用人眼的“视觉暂留”效应。当 PWM 频率足够快时（通常超过 50Hz），肉眼无法察觉灯光的闪烁，只能感知到亮度的平均值 。
    - **现象**：频率较低时能看到闪烁；频率达到一定值后，调节占空比即可实现从暗到亮的平滑过渡
![](images/008_%20外设定时器/file-20260104231033364.jpg)
2. **蜂鸣器频率调节（电子琴/报警音）**：
    - 通过改变 PWM 的**频率**，可以改变无源蜂鸣器振动产生的音调 。
3. **舵机角度控制 (Servo Control)**：
    - 舵机通常需要一个固定的周期（如 20ms） 。
    - 通过改变 PWM 的**高电平脉宽**（通常在 0.5ms 到 2.5ms 之间），精准控制舵机转动的角度（如 0° 到 180°）
![|495](images/008_%20外设定时器/file-20260104231033363.jpg)
4. **直流电机调速 (DC Motor Speed Control)**：
    - 调节占空比可以改变加在电机两端的平均电压，从而实现对转速的精准控制 。

---
### PWM 调光与传统调光的对比
为了提升开发理解深度，补充两种主流调光方式的区别：
- **DC 调光 (直流调光)**：
    - 通过改变电路的**功率**（即直接调节电压或电流的大小）来改变亮度 。
    - **优点**：无频闪 。
- **PWM 调光**：
    - 通过调节亮与灭的**时间比例**来实现亮度调节，屏幕并不是持续发光的，而是在不停地高速点亮、熄灭 。
    - **优点**：在低亮度下颜色显示更精准；
    - **注意**：亮灭交替速度较低时，敏感人群可能会感到视力疲劳
> [!tip]
>  在 STM32F407 中，PWM 的频率由定时器的计数值（Period）决定，而占空比则由比较寄存器（CCR）的值决定

## PWM 库函数的配置
在 STM32F407 中实现硬件 PWM 输出，不仅需要配置定时器的基本时基单元，还需要对 GPIO 引脚进行功能复用映射，并初始化定时器的输出比较通道
**注意**：配置 PWM 功能时，所选引脚必须在硬件上具备该定时器的 PWM 通道输出功能，否则无法输出波形
### GPIO 引脚复用功能映射
STM32F4 采用引脚复用映射机制，需要通过库函数将物理引脚连接到内部定时器的 AF（Alternate Function）外设上 。
```c
/**
  * @brief  改变指定引脚的映射关系
  * @param  GPIOx: 选择 GPIO 分组 (A..K)
  * @param  GPIO_PinSource: 指定要连接的引脚编号 (0..15)
  * @param  GPIO_AF: 选择要映射到的外设功能（如 GPIO_AF_TIM14 对应 AF9
  * @retval 无
  */
void GPIO_PinAFConfig(GPIO_TypeDef* GPIOx, uint16_t GPIO_PinSource, uint8_t GPIO_AF)
```

---

### 定时器输出比较通道初始化

PWM 功能是通过定时器的“输出比较（Output Compare）”模式实现的。每个定时器通常有 4 个独立通道 。
```c
/**
  * @brief  根据指定的参数初始化 TIMx 通道 1
  * @param  TIMx: 选择定时器外设（1..14，除了基本定时器 6 和 7
  * @param  TIM_OCInitStruct: 指向包含配置信息的结构体指针 
  * @retval 无
  */
void TIM_OC1Init(TIM_TypeDef* TIMx, TIM_OCInitTypeDef* TIM_OCInitStruct)
```

结构体核心成员配置 ：
- `TIM_OCMode`：选择 PWM 模式（PWM1 或 PWM2）。
- `TIM_OutputState`：输出使能开关。
- `TIM_OCPolarity`：设置有效电平的极性（高电平有效或低电平有效）。
> [!tip]
> - 通道 2、3、4 的配置函数分别为 `TIM_OC2Init`、`IM_OC3Init`、`TIM_OC4Init` 。

### 动态占空比控制（比较值设置）
在程序运行过程中，通过修改“捕获/比较寄存器（CCR）”的值，即可实时调节 PWM 的占空比 。
```c
/**
  * @brief  设置 TIMx 捕获比较寄存器 1 (CCR1) 的值
  * @param  TIMx: 选择定时器外设
  * @param  Compare1: 指定新的比较值，用于改变占空比 
  * @retval 无
  */
void TIM_SetCompare1(TIM_TypeDef* TIMx, uint32_t Compare1)
```

**注**：通道 2、3、4 的设置函数分别为 `TIM_SetCompare2`、`TIM_SetCompare3`、`TIM_SetCompare4` 。

---
### PWM1 与 PWM2 模式的判别逻辑

根据《STM32F4xx 中文参考手册》，PWM 模式决定了计数器（CNT）与比较值（CCR）的大小关系如何映射到输出电平上 ：
- **PWM 模式 1**：只要 `CNT < CCR1`，通道输出为**有效状态**，否则为无效状态 。
- **PWM 模式 2**：只要 `CNT < CCR1`，通道输出为**无效状态**，否则为有效状态 。
核心控制公式 ：
1. **频率**：由 `TIM_Period`（自动重装载值）决定。
2. **占空比**：由 `CompareX`（比较值）决定。
3. **有效电平**：由 `TIM_OCPolarity` 决定 。

实例分析 ： 若 `TIM_Period` 设为 99（即周期为 100），`TIM_SetCompare1` 设为 20，模式为 PWM1 且高电平有效：
- 计数器 0-19 时输出高电平，20-99 时输出低电平。
- **物理现象**：占空比为 20% 。若 LED 为低电平点亮（常见电路设计），则 LED 实际亮的时间占 80%，视觉表现为 80% 亮度 。
---

> [!tip]
> 在控制舵机或电机时，PWM 模式 1 是最常用的选择，因为它符合“计数值越大，输出能量越高”的正向逻辑。
