# 🛠️ tio 核心手册
`tio` 是一款轻量级、面向字符的串口设备终端
### 命令基本语法
```bash
tio [<选项>] <设备路径|配置名称>
```
### 常用选项

| **参数**                 | **描述**            | **提示**                       |
| ---------------------- | ----------------- | ---------------------------- |
| **`-b, --baudrate`**   | 设置波特率（默认 115200）  | ESP32 常规使用 115200 或 921600   |
| **`-e, --local-echo`** | **开启本地回显**        | 解决“输入字符看不见”的问题               |
| **`-m, --map`**        | **字符映射转换**        | 使用 `INLCRNL` 将 Enter 映射为换行   |
| **`-t, --timestamp`**  | 在每行输出前添加系统时间戳     | 调试长时间运行的逻辑时非常有帮助             |
| **`-l, --list`**       | 列出系统当前所有可用的串口设备   | 快速确认是 `ttyUSB0` 还是 `ttyACM0` |
| **`-L, --log`**        | 开启日志记录功能          | 默认保存在当前目录或指定路径               |
| **`-c, --color`**      | 对 `tio` 的状态信息进行着色 | 增强交互体验，区分系统信息与串口数据           |

### 会话内控制

在 `tio` 运行期间，所有输入都会直接发送给硬件要控制 `tio` 本身，必须使用前缀键 **`Ctrl-t`**

|**快捷键**|**功能**|**说明**|
|---|---|---|
|**`Ctrl-t` + `q`**|**退出 (Quit)**|彻底关闭会话并释放串口|
|**`Ctrl-t` + `h`**|**帮助 (Help)**|在屏幕上列出所有会话内指令|
|**`Ctrl-t` + `c`**|**清屏 (Clear)**|清除当前终端显示的所有文字|
|**`Ctrl-t` + `e`**|**开关回显**|在会话运行中实时切换回显状态|
|**`Ctrl-t` + `t`**|**开关时间戳**|实时显示或隐藏每行前的日期时间|
|**`Ctrl-t` + `b`**|**发送 Break**|发送物理中断信号（某些引导程序需要）|

### 集成Zsh 自定义函数

为了避免重复输入长命令，您已经在 `~/.zshrc` 中集成了如下函数：
```shell
# ESP32 串口调试工具
# 用法: 
#   esp            -> 使用默认 /dev/ttyUSB0 和 115200
#   esp 9600       -> 修改波特率为 9600
#   esp ttyACM0    -> 修改端口为 /dev/ttyACM0 (S3 原生口)
function esp() {
    # 1. 智能处理参数
    local port="/dev/ttyUSB0"
    local baud="115200"

    # 如果第一个参数是数字，认为是波特率；如果是路径/名称，认为是端口
    for arg in "$@"; do
        if [[ "$arg" =~ ^[0-9]+$ ]]; then
            baud="$arg"
        else
            [[ "$arg" == /dev/* ]] && port="$arg" || port="/dev/$arg"
        fi
    done

    # 2. 自动检查端口是否存在 (如果 USB0 不在，尝试找 ACM0)
    if [[ ! -e "$port" ]]; then
        if [[ "$port" == "/dev/ttyUSB0" && -e "/dev/ttyACM0" ]]; then
            port="/dev/ttyACM0"
        else
            echo -e "\e[31m✘ 错误: 未找到设备 $port\e[0m"
            echo "当前可用设备: $(ls /dev/ttyUSB* /dev/ttyACM* 2>/dev/null || echo '无')"
            return 1
        fi
    fi

    # 3. 检查权限
    if [[ ! -r "$port" ]]; then
        echo -e "\e[33m! 权限不足，尝试执行: sudo usermod -aG uucp $USER\e[0m"
    fi

    # 4. 启动 Tio
    echo -e "\e[32m✔ 正在连接: $port @ $baud\e[0m"
    echo "提示: 按 Ctrl-t 再按 q 退出"
    
    tio -b "$baud" \
        --local-echo \
        --map INLCRNL \
        --color 1 \
        "$port"
}
```
**此函数的优势：**
- **固化参数**：强制执行 `--map INLCRNL`，确保 Enter 键永远有效
- **权限预检**：可在启动前自动检查设备读写权限
- **智能切换**：可以在 `ttyUSB0` 不存在时自动尝试连接 `ttyACM0`

### 提示
1. **自动重连**：`tio` 默认支持自动重连如果您的 ESP32 重启或物理拔插，`tio` 会等待设备重新出现并自动恢复连接，无需手动干预
2. **乱码处理**：如果看到中文乱码，请确保您的终端（如 Kitty/Konsole）编码为 **UTF-8**`tio` 是纯字节透传，不会主动修改编码
3. **退出卡死**：如果 `Ctrl-t` + `q` 无效（极少见），请使用 Kitty 的快捷键关闭标签页，或在另一个窗口执行 `killall tio`
